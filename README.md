## 🚀 How to Run the Website

### Option 1: Direct File Launch
Open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox). The application runs as a high-performance Single Page Application (SPA) using client-side hash routing (`#home`, `#about-doctor`, `#booking`, `#admin`, etc.).

### Option 2: Python Local Server & REST APIs
Open a terminal in this directory and execute:
```bash
python server.py
```
Then navigate to:
- **Clinic Website:** `http://localhost:8080/#home`
- **Clinic Portal:** `http://localhost:8080/#admin`
- **Smart Booking:** `http://localhost:8080/#booking`
- **REST API Health Check:** `http://localhost:8080/api/health`
